# Feriendorf Intern

Mobile-first PWA für die Eigentümergemeinschaft des Feriendorfs in Kerschenbach.

Der erste Produktfokus liegt bewusst auf den gemeinschaftlichen Abläufen im Feriendorf: aktuelle Hinweise, Schäden, Termine, Dokumente, Abstimmungen und Nachbarschaftshilfe. Die spätere Verbindung zu einer Ferienhaus-/Gäste-App wird über stabile `community_id`- und `house_id`-Referenzen vorbereitet, ist aber nicht Teil des ersten MVP.
